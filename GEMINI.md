# Project: MarketPulse AI (PSX Focus)
## Goal
Build an autonomous financial agent system focused on the Pakistan Stock Exchange (PSX) that ingests market news and technical data, extracts insights, generates portfolio actions, and simulates trade execution.

## Tech Stack
* Backend: Node.js, Express.js
* Database: PostgreSQL 
* Orchestration: Google Antigravity (Gemini models)

## Core Directives
* The system MUST NOT just summarize. It must output actionable decisions.
* Every action generated must be simulated and logged to demonstrate a change in system state (Outcome Visualization).
